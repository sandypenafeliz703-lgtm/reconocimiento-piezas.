# Aplicación Streamlit para reconocer engranajes y motores ⚙️

Este proyecto utiliza un modelo de redes neuronales para clasificar imágenes de piezas mecánicas en dos categorías: **Engranajes** y **Motores**.

## Instalación

## Dependencias

Este proyecto requiere las siguientes librerías de Python:

- Streamlit: interfaz web interactiva
- TensorFlow: modelo neuronal
- NumPy: manejo de arreglos numéricos
- Pillow: procesamiento de imágenes

Instálalas todas con:

```bash
pip install -r requirements.txt
