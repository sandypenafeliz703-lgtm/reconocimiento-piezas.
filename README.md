# Aplicación Streamlit para reconocer engranajes y motores ⚙️

Este proyecto utiliza un modelo de redes neuronales para clasificar imágenes de piezas mecánicas en dos categorías: **Engranajes** y **Motores**.

## Instalación

Clona el repositorio y asegúrate de tener Python 3.9+ instalado.  
Instala las dependencias con:

```bash
pip install -r requirements.txt
